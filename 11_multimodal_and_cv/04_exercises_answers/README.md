# Разбор: Рамки и точность документов

Пересечение ограничивается нулём по каждой оси. IoU не сравнивает классы
объектов, поэтому само по себе не является полной detection-метрикой.
Полностью правильный документ требует совпадения всех полей; отсутствие поля
отличается от явно указанного null.

[Код решения](solution.py). Из корня:

```bash
uv run python 11_multimodal_and_cv/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях.
Для освоения темы также нужен твой отчёт и самостоятельный эксперимент из
задания.
