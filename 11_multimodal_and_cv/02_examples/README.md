# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы:
[где взять модели](../../data/models.md). Пока веса не подготовлены, эти
команды завершаются с пояснением; это не успешный запуск. Для каждого опыта
сначала предскажи результат, затем измени одно условие.

## 01_digits.py

Профиль: **CPU**. Настоящая CNN; accuracy на отложенных цифрах выше 0.85.

```bash
uv run python 11_multimodal_and_cv/02_examples/01_digits.py
```

Сравни с линейной моделью на том же split. Поменяй `padding=1` на `padding=0`
и предскажи по формуле из урока, какое число придётся исправить в `Linear`.

## 02_document_fields.py

Профиль: **CPU**. Точность полей выше доли полностью правильных документов.

```bash
uv run python 11_multimodal_and_cv/02_examples/02_document_fields.py
```

Добавь пропущенные поля и ложные документы.
