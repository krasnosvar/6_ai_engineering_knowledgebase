# Рамки и точность документов

1. Реализуй `iou(a,b)` для прямоугольников `(x1,y1,x2,y2)`. Координаты
   конечные, `x2>x1` и `y2>y1`. При неверной рамке поднимай `ValueError`;
   непересекающиеся рамки дают 0.
2. Реализуй `document_accuracy(truth,pred,fields)`: два словаря
   `doc_id → словарь полей`. Отсутствующий документ или поле считается
   ошибкой; все обязательные поля должны совпасть. Пустые `truth` или
   `fields` — `ValueError`. Лишние предсказанные документы здесь не
   учитываются.
3. Объясни, почему нужно дополнительно оценить ложные документы и ошибки OCR.

CPU; 2–3 часа. CV-расширение: сравни сеть digits с линейным классификатором
на том же split.
