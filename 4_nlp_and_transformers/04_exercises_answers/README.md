# Разбор: Устойчивая нормализация и причинная маска

Вычитание максимума сохраняет отношения exp и предотвращает переполнение.
Внимание к будущим позициям позволяет извлечь целевой токен из входа и
занизить loss. Для multi-head attention d_model делится на число heads;
изменение архитектуры меняет эксперимент даже при одинаковом количестве шагов.

В `causal_allowed` длина проверяется через `type(length) is not int`, а не
`isinstance(length, int)`: в Python `bool` — подкласс `int`, и
`isinstance(True, int)` равно `True`. Без этой проверки `causal_allowed(True)`
молча вернул бы маску длины 1.

[Код решения](solution.py). Из корня:

```bash
uv run python 4_nlp_and_transformers/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях. Для
освоения темы также нужен твой отчёт и самостоятельный эксперимент из задания.
