# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы:
[где взять модели](../../data/models.md).
Пока веса не подготовлены, эти команды завершаются с пояснением; это не
успешный запуск. Для каждого опыта сначала предскажи результат, затем измени
одно условие.

## 01_bpe.py

После [урока о токенизации](../01_theory/01_tokenization.md). Профиль:
**CPU**. Из частот пар строятся merges; новое слово разбивается, исходный
текст восстанавливается. Первые три объединения совпадают с ручным разбором в
уроке.

```bash
uv run python 4_nlp_and_transformers/02_examples/01_bpe.py
```

Измени частоты корпуса и сравни границы токенов. Объясни зависимость
токенизации от языка.

## 02_attention.py

После [урока об attention](../01_theory/02_attention.md). Профиль: **CPU**.
Строки весов суммируются в 1; будущее не влияет на прошлое.

```bash
uv run python 4_nlp_and_transformers/02_examples/02_attention.py
```

Нарушь маску и убедись, что проверка это обнаруживает.

## 03_tiny_transformer.py

После уроков о [блоке Transformer](../01_theory/03_transformer_block.md) и
[обучении языковой модели](../01_theory/04_architectures_and_lm_training.md).
Профиль: **CPU**. Loss падает примерно с 3.2 до 0.25. Сгенерированный текст
начинается похоже на обучающий («metrics show errors. logs explain…»), но
быстро сбивается в бессмыслицу вроде «rstarin rerrics s s st». Это нормально:
сеть крошечная, учится 100 шагов на одной повторяющейся строке и запомнила
лишь самые частые куски. Не ожидай связного текста.

```bash
uv run python 4_nlp_and_transformers/02_examples/03_tiny_transformer.py
```

Измени корпус; отдели другой текст для оценки обобщения.
