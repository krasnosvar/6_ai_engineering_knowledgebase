# Устойчивая нормализация и причинная маска

1. Реализуй `softmax(values)` на stdlib. Пустой список, NaN и бесконечные
   значения — ValueError; числа порядка 1000 не должны вызывать переполнение.
   Подсказка: `math.exp(1000)` не помещается в float. Приём «вычти максимум
   перед экспонентой» разобран вручную в [уроке о
   нейроне](../../3_neural_networks/01_theory/01_neurons_and_backprop.md).
2. Реализуй `causal_allowed(length)` — квадратный список bool: строка i видит
столбцы j<=i. length должен быть положительным целым, bool не допускается.
3. В tiny Transformer измени число heads, сохраняя делимость d_model. Объясни,
почему train loss с подсматриванием будущего не является достижением. CPU; 2–3
часа плюс эксперимент.

`raise ValueError("...")` — так функция сообщает «мне дали недопустимый вход»
и сразу прекращает работу; проверка ожидает именно эту ошибку. Если
исключения, `isinstance` или вложенные списки пока незнакомы, сначала пройди
минимум Python из [раздела 0](../../0_lab_setup/README.md).
