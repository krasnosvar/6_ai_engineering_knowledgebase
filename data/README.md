# Учебные данные и модели

`documents.json`, `queries.json`, `tickets.json` и `sft.json` — авторские
синтетические учебные данные, созданные для этого курса. Реальных обращений,
персональных данных и production-конфигураций здесь нет. Разрешено использовать
эти четыре набора по CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/
. Это разрешение относится к данным, а не автоматически ко всему коду и тексту
репозитория.

Наборы маленькие и намеренно простые. Хорошая метрика на них подтверждает работу
механики, но не качество продукта. `split` определяет назначение строки; меняя
алгоритм по test, ты превращаешь test в validation. Для итоговых проектов собери
новую проверочную выборку, проверь происхождение, лицензию, дубликаты и
согласованность разметки.

Изображения цифр берутся из `sklearn.datasets.load_digits`: набор встроен в
установленный scikit-learn, отдельная загрузка не нужна. Это уменьшенные
изображения 8×8; происхождение описано в
[документации](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html).

Открытая модель:
[SmolLM2-135M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct),
лицензия Apache-2.0 согласно карточке модели. Преимущественно англоязычная
учебная модель; для неё примеры запросов и SFT на английском. Это не
рекомендация современной модели для русского production-продукта. Файлы модели
не входят в Git.

Модели не скачиваются автоматически. Прямые ссылки, revision и перечень файлов —
[models.md](models.md). MODEL-лабы явно останавливаются, если локальные веса
отсутствуют.
