# Где взять модели, когда они понадобятся

Сейчас ничего скачивать не нужно. Математика, классический ML, маленькие
нейросети, учебный Transformer, проверки качества и большая часть упражнений
работают без весов. Все MODEL-примеры используют только локальные файлы
(`local_files_only=True`).

## Первая языковая модель

- [Карточка
  SmolLM2-135M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct).
- [Файлы зафиксированной
  версии](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct/tree/12fd25f77366fa6b3b4b768ec3050bf629380bac).
- 135 млн параметров, преимущественно английский язык, лицензия Apache-2.0.
- Весовой файл около 257 MiB; весь нужный набор около 260 MiB. RAM нужна сверх
  этого.
- Использование: инференс, RAG, выбор инструмента, короткая CPU LoRA.

Когда дойдёшь до MODEL-лабораторной, скачай с указанной страницы файлы:
`config.json`, `generation_config.json`, `model.safetensors`,
`special_tokens_map.json`, `tokenizer.json`, `tokenizer_config.json`,
`merges.txt`, `vocab.json`. Положи их непосредственно в
`artifacts/models/smollm2-135m/` относительно корня репы.
Список и commit SHA также сохранены в соседнем [`models.json`](models.json).

Не бери случайные файлы с других revisions: веса, конфигурация и токенизатор
должны быть согласованы. Не требуется загружать `.bin`, ONNX, checkpoints
обучения и удалённый код. Перед использованием прочитай карточку и лицензию.
Модель выбрана для доступной практики, а не как ориентир современного качества
ответов.

## Небольшая модель для поиска

- [Карточка
  all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2).
- [Фиксированная
  версия](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2/tree/1110a243fdf4706b3f48f1d95db1a4f5529b4d41).
- Англоязычные embeddings, выходной вектор 384 числа; лицензия Apache-2.0 по
  карточке.
- Веса около 87 MiB. Нужна только для дополнительного примера плотного поиска.

Файлы: `config.json`, `model.safetensors`, `tokenizer.json`,
`tokenizer_config.json`, `special_tokens_map.json`, `vocab.txt`. Размести в
`artifacts/models/minilm/`. В примере используется маскированное среднее выходов
Transformer и нормализация; это соответствует способу pooling в карточке.

## Как позже выбрать другую модель

Проверяй язык, лицензию, назначение (генерация или embeddings), память,
поддержку runtime и chat template. Проведи одинаковую оценку на своих данных.
Замена каталога без проверки архитектуры недостаточна: например, имена
LoRA-слоёв в другом семействе могут отличаться. Для русского поиска англоязычный
MiniLM не является универсальным выбором. Многоязычная альтернатива того же
класса —
[intfloat/multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small)
(вектор тоже 384 числа, лицензия MIT по карточке). Курс по умолчанию остаётся на
MiniLM. Для замены одного каталога мало: e5 по карточке ждёт префиксы `query: `
и `passage: ` перед текстом, поэтому пример придётся изменить и заново оценить
качество поиска на своих данных.
