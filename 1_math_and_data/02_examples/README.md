# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_gradient.py

Профиль: **CPU**. Аналитический и численный градиенты совпадают; w≈2, b≈1.

```bash
uv run python 1_math_and_data/02_examples/01_gradient.py
```

Измени шаг обучения и объясни расходимость.

## 02_probability.py

Профиль: **CPU**. Precision тревог около 0.15 при recall около 0.9.

```bash
uv run python 1_math_and_data/02_examples/02_probability.py
```

Измени частоту сбоев с 1% на 10%.

## 03_preprocessing.py

Профиль: **CPU**. Среднее train равно 2; использование test меняет
преобразование. Теория — [урок о массивах и
стандартизации](../01_theory/04_arrays_and_axes.md).

```bash
uv run python 1_math_and_data/02_examples/03_preprocessing.py
```

Добавь выброс в train (например, `[1, 2, 3, 100]`) и сравни `StandardScaler`
с `RobustScaler` из `sklearn.preprocessing`: как изменились значения обычных
точек? Не обучай преобразование на test.
