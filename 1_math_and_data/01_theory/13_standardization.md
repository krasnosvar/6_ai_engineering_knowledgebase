# Стандартизация признаков

В [уроке о массивах](11_arrays_and_axes.md) мы вычислили среднее каждого
столбца и вычли его. Теперь используем те же операции, чтобы привести
признаки к сравнимому масштабу, сохранив независимость проверки.

Возьмём обучающую таблицу `X = [[3, 2], [1, 0], [5, 1]]`; средние
столбцов — `[3, 1]`.

## Применение: стандартизация признаков

Число проверок и число перезапусков описывают разные признаки и могут иметь
разный разброс. Многие модели обучаются лучше, когда признаки приведены к одному
масштабу. **Стандартизация** делает это для каждого столбца:

```text
z = (x - среднее столбца) / стандартное отклонение столбца
```

Стандартное отклонение мы считали в уроке о данных: корень из среднего
квадрата отклонений. Для первого столбца отклонения `0, -2, 2`, дисперсия
`(0+4+4)/3 = 8/3`, отклонение `≈1.633`. Для второго — отклонения `1, -1, 0`,
дисперсия `2/3`, отклонение `≈0.816`. Делим центрированную таблицу на
`[1.633, 0.816]` — снова broadcasting:

```text
Z = [ [ 0.000,  1.225],
      [-1.225, -1.225],
      [ 1.225,  0.000] ]
```

Теперь у каждого столбца среднее 0 и отклонение 1, и признаки сравнимы.

Главное правило из урока о данных здесь работает в полную силу: среднее и
отклонение — это **параметры преобразования**, их вычисляют только по
обучающей части, а к новым данным применяют те же числа. Новое обращение
`[7, 1]` превращается в `[(7-3)/1.633, (1-1)/0.816] = [2.449, 0]`. Значение
2.449 честно показывает: проверок необычно много по сравнению с обучением.
Если пересчитать среднее с участием нового обращения, это различие спрячется
внутри преобразования, а проверка перестанет быть независимой.

<details>
<summary>Для любопытных: выбросы и robust scaling</summary>

Стандартизация чувствительна к выбросам. Столбец `[1, 2, 3, 4, 5, 100]`
имеет среднее 19.2 и отклонение 36.2: после стандартизации обычные значения
сжимаются в узкую полосу от -0.50 до -0.39 и почти не различаются.
**Robust scaling** вместо среднего вычитает медиану (3.5), а делит на
межквартильный размах — ширину средней половины данных (здесь 4.75 − 2.25 =
2.5). Выброс почти не влияет ни на медиану, ни на этот размах, поэтому
обычные значения остаются различимыми (от -1.0 до 0.6), а выброс получает
большое значение 38.6. Квартили — это квантили 25% и 75% из урока о данных.

</details>

## В коде

```python
import numpy as np

X = np.array([[3, 2], [1, 0], [5, 1]])
mean = X.mean(axis=0)
std = X.std(axis=0)
print(((X - mean) / std).round(3))
print(((np.array([[7, 1]]) - mean) / std).round(3))
```

`X.std` делит сумму квадратов на число строк. Если отклонение столбца
равно нулю, делить на него нельзя: библиотека должна обработать этот
случай отдельно. Не все модели требуют стандартизации; её пользу
нужно оценивать на обучающей и проверочной частях.

## Проверить понимание

1. После стандартизации по train новое обращение получило значение 4.2 по
   одному признаку. Это ошибка преобразования? Что изменится, если пересчитать
   среднее и отклонение вместе с новыми данными?

<details>
<summary>Разбор вопроса 1</summary>

Не ошибка: 4.2 означает, что значение на 4.2 отклонения больше обучающего
среднего — новые данные выглядят необычно, и это полезный сигнал. Если
пересчитать параметры с учётом новых данных, сигнал спрячется внутри
преобразования, а проверка перестанет быть независимой: мы использовали
информацию, которой при обучении не было.

</details>
