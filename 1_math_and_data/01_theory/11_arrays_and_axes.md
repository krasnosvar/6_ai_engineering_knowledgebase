# Массивы, формы и оси

В [уроке о матрицах](04_matrices.md) мы считали по строкам вручную.
Теперь разберём формы массивов NumPy, операции по осям и умножение
таблиц. Эти приёмы помогут работать сразу с группой примеров.

## Форма массива и его оси

Возьмём три обращения с двумя признаками — числом проверок и числом
перезапусков. Таблица почти как в уроке о матрицах, только у третьего
обращения пять проверок вместо четырёх: так средние получатся целыми и
их удобно считать в уме.

```text
X = [ [3, 2],
      [1, 0],
      [5, 1] ]
```

**Форма** (shape) массива — список его размеров по каждому направлению.
Здесь `(3, 2)`: три строки-обращения и два столбца-признака. Каждое такое
направление называется **осью** (axis). Ось 0 идёт по строкам — от одного
обращения к другому. Ось 1 идёт по столбцам — от одного признака к
другому. Число осей называют размерностью: у вектора одна ось, у таблицы
две.

## Сумма и среднее по оси

Операция «по оси k» сворачивает именно эту ось: складывает или усредняет
все значения вдоль неё.

- **По оси 0** складываем строки между собой и получаем по числу на каждый
  признак: `[3+1+5, 2+0+1] = [9, 3]`. Среднее по оси 0 — `[3, 1]`: в
  среднем три проверки и один перезапуск на обращение.
- **По оси 1** складываем внутри каждой строки и получаем по числу на
  каждое обращение: `[3+2, 1+0, 5+1] = [5, 1, 6]`.

Форма результата — исходная форма без свёрнутой оси: `(3, 2)` по оси 0 даёт
`(2,)`, по оси 1 — `(3,)`. Запись `(3,)` означает вектор длины 3 с одной
осью. Если свёрнутую ось нужно сохранить с размером 1, передают
`keepdims=True`: сумма по оси 1 тогда имеет форму `(3, 1)` — столбец, а не
строку. Зачем это нужно, увидим ниже.

## Broadcasting: операция между массивами разной формы

Чтобы вычесть среднее `[3, 1]` из каждого обращения, не нужен цикл. NumPy
сам «растягивает» вектор формы `(2,)` на все три строки — это называется
**broadcasting**, распространение:

```text
X - [3, 1] = [ [3-3, 2-1],      [ [ 0,  1],
               [1-3, 0-1],   =    [-2, -1],
               [5-3, 1-1] ]       [ 2,  0] ]
```

Правило: формы сравниваются с правого конца. По каждой оси размеры должны
совпадать, либо один из них должен быть равен 1 (или ось отсутствует) —
тогда эта сторона повторяется. `(3, 2)` и `(2,)`: справа 2 и 2 совпадают,
слева у вектора оси нет — вектор повторяется для каждой из трёх строк.

## То же в коде

```python
import numpy as np

X = np.array([[3, 2], [1, 0], [5, 1]])
print(X.shape)                       # (3, 2)
print(X.sum(axis=0), X.sum(axis=1))  # [9 3] [5 1 6]
print(X - X.mean(axis=0))           # центрируем каждый столбец
```

## Типичная ошибка: тихий broadcasting

Broadcasting не только удобен, но и опасен: неверная форма часто не
вызывает ошибки, а молча даёт другой результат.

Допустим, нужно поделить каждое обращение на сумму его строки, чтобы
получить доли признаков. `X / X.sum(axis=1)` падает: формы `(3, 2)` и `(3,)`
сравниваются справа, 2 и 3 не совпадают. С `keepdims=True` сумма имеет
форму `(3, 1)`, и деление работает построчно: первая строка `[3, 2] / 5 =
[0.6, 0.4]`.

Хуже, когда ошибки нет. Вектор формы `(3,)` минус столбец формы `(3, 1)`
даёт не три числа, а таблицу `(3, 3)`: каждый элемент вычитается из каждого.
Программа работает дальше, а метрика получается бессмысленной. Поэтому
после каждой операции с осями полезно напечатать `shape` и сверить его с
тем, что ты ожидаешь по смыслу.

## Проверить понимание

1. Таблица `X` имеет форму `(100, 5)`: 100 обращений, 5 признаков. Какая форма
   у `X.mean(axis=0)` и у `X.mean(axis=1)`, и что означает каждое из этих
   чисел?

<details>
<summary>Разбор вопроса 1</summary>

`X.mean(axis=0)` сворачивает ось обращений: форма `(5,)`, по одному среднему
на признак — именно это нужно для стандартизации. `X.mean(axis=1)`
сворачивает ось признаков: форма `(100,)`, среднее пяти разных признаков у
каждого обращения. Если признаки измеряются в разных единицах, такое число
обычно смысла не имеет.

</details>
