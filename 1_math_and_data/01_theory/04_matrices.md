# Матрицы и несколько обращений

В [прошлом уроке](03_vectors_and_linear_model.md) мы рассчитали ответ
для одного обращения. Теперь сделаем то же для таблицы обращений и
разберём, как форма таблицы связана с результатом.

## Несколько обращений образуют матрицу

Запишем три обращения строками:

```text
X = [ [3, 2],
      [1, 0],
      [4, 1] ]
```

Получилась таблица из трёх строк и двух столбцов — **матрица** формы `(3, 2)`.
Три строки — три наблюдения, два столбца — два признака. Буквой `X` обозначаем
все входы сразу, а маленькой `x` — вход отдельного примера.

Умножение `X @ w` вычисляет скалярное произведение каждой строки с одним
вектором весов. Результат `[16, 2, 13]`; прибавив единицу к каждому элементу,
получим `[17, 3, 14]`.

```python
import numpy as np

X = np.array([[3, 2], [1, 0], [4, 1]])
w = np.array([2, 5])
predictions = X @ w + 1
print(predictions)  # [17  3 14]
```

NumPy — библиотека операций над массивами чисел. `array` создаёт массив, а `@`
выполняет матричное умножение. Это та же работа, которую мы только что сделали
вручную для каждой строки. Длина вектора весов должна совпадать с числом
признаков.

Позже появятся массивы с большим числом осей, например группа цветных
изображений. Общее название многомерного массива — **тензор**. Сейчас
достаточно уметь назвать, что означает каждая ось конкретных данных;
подробно об осях и формах — в [уроке о массивах](11_arrays_and_axes.md).
