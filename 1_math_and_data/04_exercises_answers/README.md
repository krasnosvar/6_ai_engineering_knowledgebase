# Разбор: Градиент и косинус

Производная квадрата ошибки содержит множитель 2, а усреднение — деление на n.
Скалярное произведение делится на произведение норм. Противоположные векторы
дают -1: уже поэтому cosine нельзя трактовать как вероятность. Вектор нулей не
имеет направления.

[Код решения](solution.py). Из корня:

```bash
uv run python 1_math_and_data/03_exercises/check.py --answers
```
