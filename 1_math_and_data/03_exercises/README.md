# Градиент и косинус

1. Реализуй `mse_gradient(w,b,x,y)` для непустых списков одинаковой длины.
Возвращай пару производных по w и b; при неверной длине поднимай ValueError.
2. Реализуй `cosine(a,b)`. Нулевой вектор, пустые входы и разные длины —
   ValueError.
3. В отчёте вручную проверь градиент в одной точке; объясни, почему cosine не
   вероятность.
Профиль CPU, stdlib, без данных извне. Ориентир: 1–2 часа.
