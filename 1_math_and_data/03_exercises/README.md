# Упражнения: градиент, косинус, softmax и perplexity

Пять заданий закрепляют уроки раздела: четыре функции в коде и одно
письменное. Профиль CPU, только стандартная библиотека Python, без
данных извне. Ориентир — 2–3 часа.

## Где писать и как проверять

Функции пишутся в [`task.py`](task.py): сейчас каждая содержит
`raise NotImplementedError`. Замени эту строку своим решением. Проверка
из корня репозитория:

```bash
uv run python 1_math_and_data/03_exercises/check.py
```

Пока функция не написана, проверка остановится с `NotImplementedError` и
текстом `TODO: ...` — это ожидаемое начальное состояние, а не ошибка
окружения. Пиши функции по порядку: проверка идёт сверху вниз и
останавливается на первой ненаписанной или неверной. Когда всё верно,
последней строкой будет `PASS: 1_math_and_data student`.

Если проверка упала с `AssertionError`, посмотри на строку в
[`check.py`](check.py), которую указал Python: рядом с ней комментарий
объясняет, какой случай проверяется. `Expected ValueError` значит, что
на неверном входе функция должна поднять `ValueError`, а она вернула
результат.

## Задания

1. **`mse_gradient(w, b, x, y)`** — [урок о
   градиенте](../01_theory/07_gradients.md). Даны параметры `w`, `b` и
   списки входов `x` и правильных ответов `y`. Верни пару `(dL/dw,
   dL/db)` для MSE модели `ŷ = w×x + b`. Пустые списки или списки разной
   длины — `ValueError`. Сначала посчитай вручную: для `w = 0`, `b = 0`,
   `x = [1, 2]`, `y = [3, 5]` ответ из урока — `(-13, -8)`.
2. **`cosine(a, b)`** — [урок о
   косинусе](../01_theory/05_cosine.md). Верни косинусное
   сходство двух векторов-списков. `ValueError` для пустых входов, разных длин и
   нулевого вектора: у него нет направления, а в формуле получилось бы деление
   на ноль.
3. **Письменно**, в отчёте по [шаблону](../../other/experiment_template.md):
   вручную проверь градиент в одной точке, отличной от урока, и объясни,
   почему косинусное сходство — не вероятность.
4. **`softmax_with_temperature(logits, t)`** — [урок об экспоненте и
   softmax](../01_theory/15_classification_probabilities.md). Верни список
   вероятностей softmax от `logits / t`. Пустые `logits` и `t <= 0` —
   `ValueError`. Функция должна работать и на огромных logits вроде `[1000, 999,
   998]`: `math.exp(1000)` бросает `OverflowError`. Подсказка — в разделе урока
   о softmax: вероятности зависят только от разностей оценок. В отчёте объясни,
   почему вычитание максимума не меняет ответ.
5. **`perplexity(token_probs)`** — [урок о вероятностях
   токенов](../01_theory/16_llm_probabilities.md). Дан список вероятностей,
   которые модель дала правильным токенам. Верни экспоненту средней
   потери `-ln p`. Пустой список и вероятность вне `(0, 1]` —
   `ValueError`. В отчёте объясни, почему perplexity двух токенов с
   вероятностью 0.25 равна 4.

## Когда задание выполнено

`check.py` печатает `PASS`, и ты можешь без подсказки объяснить, почему
проверки ждут именно такие числа: `(-13, -8)` для градиента, `-1` для
противоположных векторов, `[0.665, 0.245, 0.090]` для softmax при `t = 1`.
Проверки подтверждают контракт функций; понимание показывает отчёт.

попытки.
