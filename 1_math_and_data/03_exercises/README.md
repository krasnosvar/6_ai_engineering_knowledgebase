# Градиент, косинус, softmax и perplexity

1. Реализуй `mse_gradient(w,b,x,y)` для непустых списков одинаковой длины.
Возвращай пару производных по w и b; при неверной длине поднимай ValueError.
2. Реализуй `cosine(a,b)`. Нулевой вектор, пустые входы и разные длины —
   ValueError.
3. В отчёте вручную проверь градиент в одной точке; объясни, почему cosine не
   вероятность.
4. Реализуй `softmax_with_temperature(logits,t)` — список вероятностей
   softmax от `logits / t` (мостик к LLM в [уроке
   05](../01_theory/05_exp_and_log.md)). Пустые logits и `t <= 0` —
   ValueError. Функция должна работать и на огромных logits вроде
   `[1000, 999, 998]`: `math.exp(1000)` бросает OverflowError. Подсказка:
   `e^(z-m) = e^z / e^m`; подумай, что будет, если вычесть из всех logits
   их максимум `m`. В отчёте объясни, почему ответ от этого не меняется.
5. Реализуй `perplexity(token_probs)` — экспоненту средней потери `-ln p`
   по вероятностям, которые модель дала правильным токенам. Пустой
   список и вероятность вне `(0, 1]` — ValueError. В отчёте объясни,
   почему perplexity двух токенов с вероятностью 0.25 равна 4.

Профиль CPU, stdlib, без данных извне. Ориентир: 2–3 часа.
