# Разбор: Авторизация и объединение рангов

Фильтрация перед top-k исключает чужие данные и сохраняет кандидатов своей
команды. Сырые оценки поиска имеют разный масштаб; RRF складывает вклады рангов.
Совпадение нескольких списков повышает оценку, но результат всё равно нужно
измерить на вопросах.

[Код решения](solution.py). Из корня:

```bash
uv run python 6_retrieval_and_rag/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях. Для
освоения темы также нужен твой отчёт и самостоятельный эксперимент из задания.
