# Авторизация и объединение рангов

1. Реализуй `authorized_topk(rows,tenant,k)`. Каждая строка содержит id,
tenant, score. Сначала оставь public и свою команду, затем сортируй по
убыванию score и id при равенстве. Верни первые k ID; k — положительное целое.
Tenant поступает из доверенной авторизации.
2. Реализуй `rrf(rankings,k=60)` — словарь ID→сумма 1/(k+rank), rank
начинается с 1. В одном рейтинге ID может встретиться только один раз, иначе
ValueError; k>0.
3. Для dev-вопросов измерь Recall@1 и Recall@3. Вопросы без источника учитывай
отдельно. CPU; 2–4 часа. Запиши, почему фильтрация после top-k может потерять
допустимый источник.
4. Реализуй `ann_recall_at_k(approx_ids,exact_ids,k)` из [урока о векторных
хранилищах](../01_theory/04_vector_stores.md): доля первых k ID точного
перебора, которые есть среди первых k ID приближённого поиска. ANN может
вернуть меньше k ID — это допустимо. ValueError, если k не положительное
целое, если в exact_ids меньше k ID или если в списке есть повтор.
5. Реализуй `ivf_candidates(query,centers,cell,n_probe)` — шаг поиска в IVF.
`centers` — векторы центров ячеек, `cell[i]` — номер ячейки документа i,
векторы нормированы. Выбери n_probe центров с наибольшим скалярным
произведением с query (при равенстве — меньший номер) и верни отсортированный
список номеров документов этих ячеек. ValueError, если длина query не равна
длине центра, n_probe вне 1..число центров или в cell есть номер
несуществующей ячейки. Подойдут `centers @ query` и `np.argsort` с
`kind='stable'`.

`raise ValueError("...")` — так функция сообщает «мне дали недопустимый вход»
и сразу прекращает работу; проверка ожидает именно эту ошибку. Для сортировки
пригодится `sorted(..., key=...)`, для нумерации с единицы —
`enumerate(список, 1)`. Если эти конструкции или исключения пока незнакомы,
сначала пройди минимум Python из [раздела 0](../../0_lab_setup/README.md); обе
разобраны в комментариях эталонного решения.
