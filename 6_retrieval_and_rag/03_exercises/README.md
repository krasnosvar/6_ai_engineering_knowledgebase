# Авторизация, объединение рангов и ANN

Задания 1, 2, 4 и 5 — функции в [`task.py`](task.py); их проверяет
`check.py`. Задание 3 — небольшой опыт с примером и письменный вывод.
Все задания работают на CPU без весов; на всё — 2–4 часа.

## 1. `authorized_topk(rows, tenant, k)`

Урок: [основы RAG](../01_theory/01_rag_basics.md), раздел о правах.

Дано: список словарей `{'id': ..., 'tenant': ..., 'score': ...}` —
кандидаты поиска с оценками; `tenant` пользователя из доверенной
авторизации; `k`. Сделать: оставить строки с tenant `public` и своей
командой, отсортировать по убыванию `score` (при равном score — по `id`
по возрастанию) и вернуть список первых `k` ID. Порядок важен: сначала
права, потом top-k. `ValueError`, если `k` не положительное целое (в том
числе `True`).

## 2. `rrf(rankings, k=60)`

Урок: [ранжирование](../01_theory/03_ranking.md), раздел про RRF.

Дано: список рейтингов, каждый — список ID от лучшего к худшему. Сделать:
словарь ID → сумма `1/(k + rank)` по всем рейтингам, где rank начинается
с 1. Пример из проверки: `rrf([['a','b'], ['b','c']])['b'] = 1/62 + 1/61`.
Пустой список рейтингов даёт `{}`. `ValueError`, если в одном рейтинге ID
повторяется или `k <= 0`.

## 3. Recall@1 и Recall@3 на dev (опыт, без проверки кодом)

Урок: [основы RAG](../01_theory/01_rag_basics.md); пример
[`01_search.py`](../02_examples/01_search.py).

Скопируй пример в свой файл и измени цикл: считай только вопросы со
`split == 'dev'`, для каждого — Recall@1 и Recall@3, вопрос без нужных
документов (`relevant` пуст) учитывай отдельно. Запиши оба средних и
объясни словами, почему фильтрация после top-k могла бы потерять
допустимый источник: придумай выдачу, где три лучших документа принадлежат
чужой команде.

## 4. `ann_recall_at_k(approx_ids, exact_ids, k)`

Урок: [векторные хранилища](../01_theory/04_vector_stores.md), раздел
«Идея приближённого поиска».

Дано: выдача ANN и выдача точного перебора, оба — списки ID по
убыванию сходства. Сделать: доля первых `k` ID точного перебора, которые
есть среди первых `k` ID ANN. Порядок внутри первых k не важен. ANN может
вернуть меньше `k` ID — недостающие считаются промахами, делим всё равно
на `k`. Пример: точные `[d1, d2, d3]`, ANN `[d3, d1, d9]`, k=3 → 2/3.
`ValueError`, если `k` не положительное целое (в том числе `True`), если в
`exact_ids` меньше `k` ID или если в одном из списков есть повтор.

## 5. `ivf_candidates(query, centers, cell, n_probe)`

Урок: [векторные хранилища](../01_theory/04_vector_stores.md), функция
`ivf_topk` в коде урока.

Дано: вектор запроса; `centers` — векторы центров ячеек (по строке на
центр); `cell[i]` — номер ячейки документа `i`; все векторы нормированы.
Сделать: выбрать `n_probe` центров с наибольшим скалярным произведением с
`query` (при равенстве — с меньшим номером) и вернуть отсортированный
список номеров документов этих ячеек. Пустая ячейка просто не добавляет
документов. `ValueError`, если длина `query` не равна длине центра,
`n_probe` вне `1..число центров` или в `cell` есть номер несуществующей
ячейки или его номер не целый. Пустой `cell` означает, что документов
нет, и даёт пустой результат. Подойдут `centers @ query`,
`np.argsort(-scores, kind='stable')`,
`np.isin` и `np.flatnonzero` — те же операции, что в коде урока.

## Python в этих заданиях

- `raise ValueError('описание')` — функция сообщает «мне дали недопустимый вход»
  и сразу прекращает работу; `check.py` проверяет, что ошибка возникает.
  Подробнее —
  [исключения](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/1_python_fundamentals/07_exceptions/01_theory/01_exceptions.md).
- `sorted(rows, key=lambda r: (-r['score'], r['id']))` сортирует по значению,
  которое вернула функция `key`; минус даёт убывание — [lambda и
  sorted](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/2_functions_and_decorators/01_theory/01_lambdas.md).
- `set` удобно для повторов и пересечений: `len(set(x)) != len(x)` — есть
  повтор, `set(a) & set(b)` — общие элементы — [множества и
  словари](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/1_python_fundamentals/05_collections/01_theory/01_lists_tuples_sets_dicts.md).
- `enumerate(ranking, 1)` выдаёт пары `(1, первый), (2, второй), ...` —
  удобно для rank с единицы.
- `type(k) is not int` отсекает и `True`: в Python `bool` — разновидность
  `int`, и `isinstance(True, int)` вернёт `True`.
