# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_search.py

Профиль: **CPU**. ID источников, Recall@3 и отсутствие чужих документов.

```bash
uv run python 6_retrieval_and_rag/02_examples/01_search.py
```

Считай dev/test отдельно и выдели вопросы без ответа.

## 02_rag.py

Профиль: **MODEL**. Контекст своей команды и настоящий ответ LLM.

```bash
uv run python 6_retrieval_and_rag/02_examples/02_rag.py
```

Проверь факт 43 минуты и ссылку d9; неверный ответ запиши как ошибку.

## 03_dense_hybrid.py

Профиль: **EMBEDDING**. Результаты dense, lexical и RRF на английском запросе.

```bash
uv run python 6_retrieval_and_rag/02_examples/03_dense_hybrid.py
```

Проверь несколько перефразировок и exact-match запросов.

## 04_chunking.py

Профиль: **CPU**. Сравниваются сохранность факта и число индексируемых слов при
разных окнах.

```bash
uv run python 6_retrieval_and_rag/02_examples/04_chunking.py
```

Подбери окно, сохраняющее условие исключения. Затем измерь реальный поиск по
фрагментам.
