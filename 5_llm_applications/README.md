# Как превратить генерацию текста в приложение

Языковая модель умеет продолжать текст. Приложению нужен определённый
результат: например, категория обращения из разрешённого списка. Разберём,
как задать задачу, проверить ответ, обработать ситуации, когда запрос не
завершился вовремя, посчитать стоимость вызовов и выбрать, где запускать
модель — у провайдера или у себя.

Перед этим разделом: [Как языковая модель работает с
текстом](../4_nlp_and_transformers/README.md).

4. [Сколько стоит вызов модели](01_theory/04_api_tokens_cost_caching.md) —

Читай уроки последовательно. Перед раскрытием разбора ответь на вопросы
самопроверки своими словами; если объяснение пока не получается, вернись к
разобранному примеру.

## Как перейти к практике

Без весов выполни [02_schema.py](02_examples/02_schema.py) после урока 1
и [03_retry_budget.py](02_examples/03_retry_budget.py) после урока 2: они
проверяют подготовленные ответы и моделируют статусы запросов.
[01_generate.py](02_examples/01_generate.py) — первая встреча с настоящей
LLM: ему нужны веса SmolLM2-135M, скачанные вручную по [списку
моделей](../data/models.md). Без весов он только сообщает, что модель
отсутствует; это не провал курса, а отложенный шаг. Код из уроков 03–05
копируется из текста урока в файл и запускается без сети и весов.

Все команды выполняются из корня репозитория. [Инструкция к
примерам](02_examples/README.md) содержит команды и ожидаемые результаты.
Затем открой [самостоятельные задания](03_exercises/README.md); [ответы и
разбор](04_exercises_answers/README.md) используй после своей попытки.

## Когда двигаться дальше

Можешь отличить корректный JSON от правильного решения задачи и объяснить,
какие ошибки стоит повторять, а какие нужно исправлять. Можешь вручную
оценить месячную стоимость вызовов и память под веса модели, а изменение
prompt проверяешь на наборе примеров, а не на одном удачном ответе.
