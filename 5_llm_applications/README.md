# Как превратить генерацию текста в приложение

Языковая модель умеет продолжать текст. Приложению нужен определённый результат: например, категория обращения из разрешённого списка. Разберём, как задать задачу, проверить ответ и обработать ситуации, когда запрос не завершился вовремя.

Перед этим разделом: [Как языковая модель работает с текстом](../4_nlp_and_transformers/README.md).

## Порядок чтения

1. [Как поставить задачу модели](01_theory/01_structured_output.md) — инструкция, примеры и проверка структуры и смысла ответа.
2. [Что происходит вокруг вызова](01_theory/02_runtime_contract.md) — таймауты, повторные попытки и общий срок выполнения.

Читай уроки последовательно. Перед раскрытием разбора ответь на вопросы самопроверки своими словами; если объяснение пока не получается, вернись к разобранному примеру.

## Как перейти к практике

Без весов выполни 02_schema.py и 03_retry_budget.py: они проверяют подготовленные ответы и моделируют статусы запросов. 01_generate.py использует готовую LLM и остаётся следующим практическим шагом после ручной подготовки модели.

Все команды выполняются из корня репозитория. [Инструкция к примерам](02_examples/README.md) содержит команды и ожидаемые результаты. Затем открой [самостоятельные задания](03_exercises/README.md); [ответы и разбор](04_exercises_answers/README.md) используй после своей попытки.
