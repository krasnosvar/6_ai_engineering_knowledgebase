# Контракт ответа, стоимость вызова и память модели

1. Реализуй `parse_ticket(raw)` — JSON-объект ровно с полями ticket_id и
label. ticket_id — непустая строка; label — database/network/access/unknown.
Ошибка — ValueError. Не извлекай JSON из произвольной прозы и не исправляй
значения молча.
2. Реализуй `remaining_tokens(limit,input_tokens,reserved_output)` — доступный
остаток. Все значения целые >=0 (bool запрещён); если бюджет превышен,
ValueError.
3. Напиши пять семантически неправильных ответов, проходящих схему, и способ
их оценки. CPU, stdlib; 2–3 часа. MODEL-расширение выполнять позже, после
ручной подготовки весов.
4. Реализуй `call_cost(input_tokens,output_tokens,cached_tokens,prices)` —
стоимость вызова из [урока 04](../01_theory/04_api_tokens_cost_caching.md).
`prices` — словарь ровно с ключами `input`, `cached_input`, `output`: цены
за миллион токенов, числа >=0. `cached_tokens` — часть входа, взятая из
кэша, а не добавка к нему. Токены — целые >=0 (bool запрещён);
`cached_tokens > input_tokens`, лишний или недостающий ключ цены —
ValueError. Цены в проверках выдуманные, как и в уроке.
5. Реализуй `wrap_untrusted(text,tag)` из [урока
03](../01_theory/03_prompting_and_context.md): вернуть
`<tag>\ntext\n</tag>`, где каждое `</tag>` внутри текста заменено на
`</ tag>`. Текст не строка или тег не из строчных латинских букв —
ValueError. В отчёте объясни, почему разделители снижают риск prompt
injection, но не устраняют его.
6. Реализуй `weights_memory_gb(params,bits)` из [урока
05](../01_theory/05_local_runtimes.md) — память под веса в GB (10⁹
байтов): параметры × биты / 8. Оба аргумента — целые >0; `7e9` — float,
пиши `7_000_000_000`. В отчёте объясни, почему реальный файл Q4 больше
результата и что ещё займёт память при запуске.

`raise ValueError("...")` — так функция сообщает «мне дали недопустимый вход»
и сразу прекращает работу; проверка ожидает именно эту ошибку. Учти, что
`json.loads` на тексте, который не является JSON, сам бросает
`json.JSONDecodeError` — а это подкласс `ValueError`, так что такой случай уже
подходит. Если исключения, `isinstance` или `type(...)` пока незнакомы,
сначала пройди минимум Python из [раздела 0](../../0_lab_setup/README.md).
