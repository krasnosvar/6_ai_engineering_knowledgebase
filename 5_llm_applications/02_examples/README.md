# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_generate.py

Профиль: **MODEL**. Настоящий локальный ответ и число токенов; качество оценивай
отдельно.

```bash
uv run python 5_llm_applications/02_examples/01_generate.py
```

Сравни две инструкции на своих dev-вопросах.

## 02_schema.py

Профиль: **CPU**. Один допустимый и три недопустимых ответа.

```bash
uv run python 5_llm_applications/02_examples/02_schema.py
```

Добавь валидный JSON с неверным смыслом.

## 03_retry_budget.py

Профиль: **CPU**. Повторяются только временные ошибки и соблюдается лимит
попыток.

```bash
uv run python 5_llm_applications/02_examples/03_retry_budget.py
```

Добавь общий временной бюджет. Объясни отличие retry генерации от retry платежа.
