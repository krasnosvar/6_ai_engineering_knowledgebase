# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_bootstrap.py

Профиль: **CPU**. Разность долей верных ответов и приближённый парный интервал.

```bash
uv run python 7_evaluation_and_safety/02_examples/01_bootstrap.py
```

Увеличь число независимых примеров; не просто дублируй строки.

## 02_access.py

Профиль: **CPU**. d9 разрешён, d10 не передаётся команде a.

```bash
uv run python 7_evaluation_and_safety/02_examples/02_access.py
```

Добавь ещё одну команду и отрицательные проверки.

## 03_judge_agreement.py

Профиль: **CPU**. Доля согласия, kappa и ложные одобрения судьи показывают
разные стороны оценки.

```bash
uv run python 7_evaluation_and_safety/02_examples/03_judge_agreement.py
```

Добавь перестановку A/B в реальном исследовании судьи; сначала подготовь
человеческую рубрику.
