# Срезы качества и контроль источников

1. Реализуй `slice_accuracy(rows)`: строки содержат `slice` и `correct`
   (bool). Верни словарь с долей верных ответов (accuracy) для каждого среза.
   Пустой набор — `ValueError`. Если `correct` не bool (например, строка
   `'yes'` или число `1`), тоже `ValueError`: проверка ловит именно это.
2. Реализуй `citations_allowed(cited_ids,context_ids)`: True, если все
   процитированные ID действительно находились в переданном контексте.
   Пустой список цитат здесь допустим.
3. Создай рубрику ручной проверки обоснованности: разрешённая цитата ещё не
   означает, что она подтверждает утверждение. Приведи два контрпримера.

CPU; 2–3 часа. Дополнительно оцени парный интервал изменения доли верных
ответов на 20 задачах.

`raise ValueError('описание')` — так функция сообщает «мне дали неверные
данные» и останавливается; `check.py` проверяет, что ошибка действительно
возникает. Если исключения ещё не знакомы — см. минимум Python в
[0_lab_setup](../../0_lab_setup/README.md).

[шаблону отчёта](../../other/experiment_template.md).
