# Срезы качества, источники, судья и вызов инструмента

Задания 1, 2, 4, 5 и 6 — функции в [`task.py`](task.py); их проверяет
`check.py`. Задание 3 и дополнительный опыт — письменные. Всё работает на
CPU без весов; на всё — 2–3 часа.

## 1. `slice_accuracy(rows)`

Урок: [сравнение версий](../01_theory/02_comparing_versions.md), раздел
о срезах.

Дано: список словарей `{'slice': 'rare', 'correct': False}` — результат
каждого вопроса и его срез. Сделать: словарь срез → доля верных ответов
(accuracy) в этом срезе. Пример из проверки: `rare` 0 из 1 → 0.0,
`normal` 1 из 2 → 0.5. `ValueError`, если набор пуст или `correct` не
bool: строка `'yes'` и число `1` тоже ошибка, иначе 1 молча посчиталось
бы успехом.

## 2. `citations_allowed(cited_ids, context_ids)`

Урок: [проверка приложения](../01_theory/01_free_text_evaluation.md),
раздел «Что можно проверить автоматически».

Дано: ID, на которые сослался ответ, и ID документов, переданных в
контекст. Сделать: `True`, если каждый процитированный ID был в контексте.
Пустой список цитат допустим и даёт `True`. Это первый уровень проверки
ссылки из [основ RAG](../../6_retrieval_and_rag/01_theory/01_rag_basics.md):
ID существует, но подтверждает ли он утверждение — проверяет задание 3.

## 3. Рубрика обоснованности (письменно)

Урок: [проверка приложения](../01_theory/01_free_text_evaluation.md) и
[рубрика судьи](../01_theory/04_llm_as_judge.md).

Составь 3–5 критериев «да / нет» для ручной проверки, что ответ опирается
на источники. Приведи два контрпримера, где `citations_allowed` вернёт
`True`, а ответ всё равно не обоснован: например, ссылка на d9 с числом
100 минут вместо 43.

## 4. `position_bias_check(verdicts_ab, verdicts_ba)`

Урок: [судья](../01_theory/04_llm_as_judge.md), «Пример вручную:
перестановка A/B».

Дано: два списка победителей `'A'` или `'B'` по вопросам: в первом A
показан первым, во втором — B. Сделать: словарь `consistent` (сколько
вопросов с одинаковым вердиктом в обоих порядках), `inconsistent` и
`first_wins` — сколько раз из `2·n` победил показанный первым. На данных
урока: 6, 4 и 14. `ValueError`: пустые списки, разная длина или значение
не `'A'`/`'B'` (например, `'tie'`).

## 5. `judge_calibration(human, judge)`

Урок: [судьи и выпуск](../01_theory/03_judges_and_release.md) (формула
kappa) и [судья](../01_theory/04_llm_as_judge.md) (калибровка).

Дано: метки 0/1 человека и судьи для одних и тех же ответов (1 — «да»).
Сделать: словарь `agreement`, `kappa` и `false_approvals` — сколько раз
человек сказал 0, а судья 1. На данных урока 4: 0.75, 0.5 и 4.
`ValueError`: пустые списки, разная длина, метка не int 0/1 (в том числе
`True`) или `p_e = 1` — оба всегда ставят одну метку, kappa = 0/0 не
определена.

## 6. `guard_tool_call(call, allowlist, needs_approval)`

Урок: [защитные слои](../01_theory/05_guardrails_and_injection.md), слои
2 и 4.

Дано: `call` — словарь, который предложила модель, с ключом `tool`
(имя инструмента); список разрешённых инструментов; список тех, что
требуют подтверждения человеком. Сделать: `'deny'`, если инструмента нет
в allowlist (сравнение точное: `'Search'` не равно `'search'`),
`'confirm'`, если он в needs_approval, иначе `'allow'`. `ValueError`,
если в `call` нет строки `tool` или needs_approval содержит инструмент вне
allowlist — это ошибка настройки.

## Python в этих заданиях

- `raise ValueError('описание')` — функция сообщает «мне дали неверные данные» и
  останавливается —
  [исключения](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/1_python_fundamentals/07_exceptions/01_theory/01_exceptions.md).
- Словарь-счётчик `counts[key] = counts.get(key, 0) + 1` и проверка подмножества
  `set(a) <= set(b)` — [множества и
  словари](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/1_python_fundamentals/05_collections/01_theory/01_lists_tuples_sets_dicts.md).
- `zip(a, b)` идёт по парам `(a[0], b[0]), (a[1], b[1]), ...` — так
  сравнивают оценки одного ответа.
- `type(x) is not bool` / `type(x) is not int` — точная проверка типа:
  `True == 1` в Python, и `isinstance(True, int)` вернёт `True`.
