# Разбор: Срезы качества и контроль источников

Большой обычный срез может скрыть провал редких случаев. Проверка ссылок защищает
от выдуманных ID, но не от ссылки на нерелевантный факт. Рубрика должна разделять
существование источника, поддержку утверждения и полноту ответа.

[Код решения](solution.py). Из корня:

```bash
uv run python 7_evaluation_and_safety/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях.
Для освоения темы также нужен твой отчёт и самостоятельный эксперимент из задания.
