# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_xor.py

Профиль: **CPU**. Loss уменьшается; предсказания [0,1,1,0].

```bash
uv run python 3_neural_networks/02_examples/01_xor.py
```

Убери нелинейность и объясни результат.

## 02_overfit.py

Профиль: **CPU**. Таблица train/validation loss по эпохам: train loss падает до
0, validation loss растёт с первой эпохи. Итог: train accuracy 1.000, validation
0.464 — около монетки.

```bash
uv run python 3_neural_networks/02_examples/02_overfit.py
```

Уменьши сеть и сравни скорость запоминания.

## 03_accumulation.py

Профиль: **CPU**. Градиент полного batch совпадает с правильно взвешенным
накоплением.

```bash
uv run python 3_neural_networks/02_examples/03_accumulation.py
```

Замени sum/len(x) на mean/2 и найди расхождение для размеров 2 и 3.
