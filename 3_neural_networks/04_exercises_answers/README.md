# Разбор: Градиенты и masked pooling

Добавленные пустые позиции (padding) не должны смещать среднее векторов
последовательности. Маска формы (B,T) получает ось D через `unsqueeze(-1)` —
(B,T,1) — и умножается на hidden: пустые позиции обнуляются. Сумма по оси T
(`sum(dim=1)`) даёт (B,D), а делитель — число реальных позиций каждой
последовательности (`mask.sum(dim=1, keepdim=True)`, форма (B,1)). Если реальных
позиций нет, честнее явно остановиться с ошибкой, чем выдать нулевой «успешный»
вектор. В разделе 4 такими позициями станут слова и части слов текста (токены),
а векторы — их числовыми представлениями (embedding). `eval()` меняет поведение
слоёв вроде Dropout и BatchNorm, а `no_grad()` отключает запись операций для
производных — это разные переключатели.
