# Шаг обучения и усреднение с маской

Профиль CPU, нужен PyTorch из окружения курса; 2–3 часа. Два задания
программируются в [task.py](task.py), третье — письменное.

## 1. `one_step(model, optimizer, x, y)`

**Тема:** [урок о PyTorch](../01_theory/02_pytorch_basics.md) (шаг обучения)
и [урок о цикле обучения](../01_theory/03_batches_and_training_loop.md)
(зачем обнулять градиенты).

**Дано:** классификатор `model` (любой `nn.Module`, выдающий logits формы
`(batch, классы)`), его оптимизатор, входы `x` и целые номера классов `y`.

**Сделать:** включить `model.train()`, затем выполнить один шаг обучения:
обнулить градиенты, вычислить cross entropy по logits, вызвать `backward()`
и `step()`. Вернуть loss как обычное число Python (`float`), а не тензор.

**Что проверяется:** перед вызовом в `.grad` модели специально кладутся
большие «старые» градиенты. Если их не обнулить, веса после шага не совпадут
с весами второй, чистой модели.

## 2. `masked_mean(hidden, mask)`

**Тема:** [урок о стабильности](../01_theory/05_stability_and_checkpoints.md),
раздел о masked mean; оси и суммирование по оси — [урок о массивах и
тензорах](../../1_math_and_data/01_theory/12_tensor_operations.md).

**Дано:** `hidden` формы `(B, T, D)` и `mask` формы `(B, T)` из 0 и 1. B — число
последовательностей в batch, T — число позиций после выравнивания (включая
пустые), D — длина вектора в позиции. 1 в маске — реальная позиция, 0 —
добавленная пустая.

**Сделать:** вернуть тензор `(B, D)` — для каждой последовательности среднее
векторов только по позициям с 1.

**Ошибки входа:** если в какой-то строке маски нет ни одной 1, поднять
`ValueError` (`raise ValueError('текст')`): среднее пустого набора не
определено. Проверка подаёт маску из одних нулей и ждёт именно `ValueError`.
Эталон также отвергает неверные формы и значения маски не 0/1 — это хорошая
практика, но `check.py` её не требует.

Ручной пример из проверки: векторы `[1,3]`, `[3,5]`, `[99,99]` с маской
`[1,1,0]` дают `[2, 4]`; `[99, 99]` не должен попасть в среднее.

## 3. Письменно

1. Объясни, почему `model.eval()` не заменяет `torch.no_grad()`.
2. Дополнительный опыт: в копии своего `one_step` убери `zero_grad()`, сделай
   два шага подряд на одних данных и сравни `.grad` после второго
   `backward()` с градиентом одного шага. Предскажи результат до запуска.

## Как проверить

Пиши решение в `task.py`, не меняя имена функций. Затем из корня репозитория:

```bash
uv run python 3_neural_networks/03_exercises/check.py
```

- До решения проверка падает с `NotImplementedError: TODO: ignore padded
  positions` — первой проверяется `masked_mean`. Это заготовка `raise
  NotImplementedError` в `task.py`, а не ошибка установки.
- `AssertionError` с номером строки `check.py` — результат отличается от
  ожидаемого: открой строку и сравни вход с ожиданием.
- `AssertionError: Expected ValueError` — функция не отвергла пустую маску.
- Всё верно, когда в конце печатается `PASS: 3_neural_networks student`.
