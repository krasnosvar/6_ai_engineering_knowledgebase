# AI Engineering Knowledge Base

Курс на русском для тех, кто впервые изучает искусственный интеллект и
хочет научиться строить приложения на языковых моделях: чат-ботов с
поиском по документам, классификаторы обращений, ассистентов, которые
вызывают инструменты. Курс начинается с того, как модель вообще учится
на примерах, и доходит до оценки качества, дообучения и эксплуатации.

## Подходит ли тебе курс

Нужен базовый Python: функции, списки, словари, циклы, исключения,
простые классы и запуск программы из терминала. Сам язык здесь не
объясняется. Проверить себя можно [входной
диагностикой](0_lab_setup/03_exercises/README.md), а пробелы закрыть по
урокам [Python-базы](0_lab_setup/python_minimum.md), на которые она
ссылается.

Знания AI и высшей математики не нужны: достаточно школьной арифметики.
Каждое понятие вводится на маленьком примере, который можно посчитать
вручную, а затем повторить в коде.

Прохождение курса не делает профессионалом само по себе. Оно даёт
понимание методов и учебную практику; опыт работы с реальными
требованиями, данными и сбоями приходит только на проектах.

## Чему научишься

- Объяснять, что происходит при обучении модели, и находить причину,
  когда обучение идёт не так.
- Честно проверять качество: отделять данные для проверки, выбирать
  метрику, отличать настоящее улучшение от случайности.
- Понимать, как языковая модель читает текст и выбирает следующее слово.
- Встраивать готовую модель в программу: получать от неё ответ нужного
  формата, считать стоимость запросов, обрабатывать сбои.
- Строить поиск по документам с источниками и правами доступа (RAG).
- Дообучать небольшую модель и ограничивать агента, который вызывает
  инструменты.
- Измерять задержки и память, выпускать и откатывать версии.

## Коротко о словах AI, ML, NLP и LLM

**AI** (искусственный интеллект) — общее название программ, которые
делают работу, обычно требующую человека. **ML** (машинное обучение) —
часть AI, где способ получить ответ подбирается по примерам, а не
пишется правилами. **NLP** — задачи с текстом на естественном языке.
**LLM** — большая языковая модель, нейросеть, обученная продолжать
текст. Подробно эти слова разобраны в [первом
уроке](1_math_and_data/01_theory/00_rules_and_learning.md).

Основной путь курса: основы ML → нейросети → устройство языковых
моделей → приложения на готовых LLM. Компьютерное зрение (работа с
изображениями) дано как вводная соседняя специализация.

## С чего начать

1. Открой [раздел 0](0_lab_setup/README.md) и подготовь компьютер.
2. Установи окружение и пройди диагностику Python — шаги описаны там же.
3. Дальше иди по [маршруту обучения](0_lab_setup/learning_path.md): в нём
   расписано первое занятие и условия перехода между разделами.

Внутри раздела порядок всегда один: README раздела называет уроки по
порядку → урок объясняет идею и разбирает её вручную → вопросы
самопроверки → пример в `02_examples/`, который показывает идею в коде →
самостоятельное задание в `03_exercises/` → разбор в
`04_exercises_answers/` после своей попытки.

Все команды выполняются из корня репозитория:

```bash
uv sync --frozen                                    # поставить библиотеки
uv run python 0_lab_setup/02_examples/01_doctor.py  # проверить машину
uv run python 1_math_and_data/03_exercises/check.py # проверить решение
```

`uv` — менеджер окружения Python; что это и как его установить,
объясняет [урок о среде](0_lab_setup/01_theory/01_hardware.md).

## Компьютер и готовые модели

Основной маршрут работает на обычном ноутбуке без видеокарты: CPU и
16 ГБ RAM. Для экспериментов с локальной моделью и дообучения
рекомендуется 32–64 ГБ. Это ориентиры, а не замеры на твоей машине.
Платные API не нужны.

Разделы 0–4 полностью проходятся без скачивания моделей: маленькие
модели обучаются прямо в примерах на встроенных данных. Готовые веса
понадобятся начиная с раздела 5, и только для отдельных примеров с
пометкой **MODEL** или **EMBEDDING**. Их не нужно скачивать заранее: где
взять файлы и куда положить, описано на [странице
моделей](data/models.md). Без весов такие примеры только сообщают, каких
файлов не хватает.

Пометки профилей в примерах: **CPU** — без ускорителя и без весов;
**MODEL** — нужна скачанная языковая модель (135 млн параметров, около
260 MiB); **EMBEDDING** — нужна небольшая модель для поиска по смыслу;
**GPU extension** — дополнительные опыты с ускорителем, необязательны.
Особенности Intel Arc и Fedora — в [уроке о
среде](0_lab_setup/01_theory/01_hardware.md).

## Как учиться по материалам

Запуск примера не равен освоению темы. Перед запуском предскажи
результат, после — сравни и измени одно условие. В заданиях сначала
работай без разбора. Не обязательно понимать урок целиком с первого
раза: разбери его пример, ответь на вопрос и только потом прочитай
ответ. Части с пометкой «можно вернуться позже» и блоки «Для
любопытных» при первом чтении можно пропустить.

Свои опыты сохраняй в `artifacts/` (каталог в Git не попадает) по
[шаблону отчёта](other/experiment_template.md). [Матрица
компетенций](12_capstones/01_theory/02_competencies.md) описывает, что
должен уметь показать выпускник курса.
