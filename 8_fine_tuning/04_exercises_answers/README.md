# Разбор: Разметка loss и число параметров

Без маски prompt loss поощряет воспроизведение инструкции. При answer-only loss
учим нужный ответ; EOS обычно также включают в целевые токены. Causal LM в Transformers
сама выполняет сдвиг logits и labels. LoRA экономит обучаемые параметры, но не убирает
базовую модель из памяти.

[Код решения](solution.py). Из корня:

```bash
uv run python 8_fine_tuning/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях.
Для освоения темы также нужен твой отчёт и самостоятельный эксперимент из задания.
