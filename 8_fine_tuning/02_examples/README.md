# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_lora_math.py

Профиль: **CPU**. 8192 параметра полной матрицы против 768 адаптера;
эквивалентность формул.

```bash
uv run python 8_fine_tuning/02_examples/01_lora_math.py
```

Измени rank и посчитай экономию.

## 02_train_adapter.py

Профиль: **MODEL**. Настоящее обучение и artifacts/adapter/experiment.json с
base/adapter-оценкой.

```bash
uv run python 8_fine_tuning/02_examples/02_train_adapter.py
```

Не меняй параметры по test; для следующего опыта подготовь dev.

По умолчанию 12 коротких шагов. Результат не гарантирует улучшения.
`artifacts/adapter/` должен отсутствовать: предыдущий опыт сначала сохрани под
другим именем. Не удаляй свой отчёт ради повторного запуска. Команда не
перезаписывает существующий адаптер.

## 03_tiny_adapter.py

Профиль: **CPU**. Адаптер обучается на train, уменьшает MSE на отложенных
данных и не меняет базовую матрицу.

```bash
uv run python 8_fine_tuning/02_examples/03_tiny_adapter.py
```

Уменьши rank до 1 и объясни ограничение представления поправки. Конструкции
`class Adapted(nn.Module)`, `nn.Parameter` и оптимизатор разобраны в [основах
PyTorch](../../3_neural_networks/01_theory/02_pytorch_basics.md).
