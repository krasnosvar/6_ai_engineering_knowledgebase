# Разметка loss и число параметров

1. Реализуй `answer_labels(prompt_ids,answer_ids,pad_to)` — список меток
   длины pad_to: на местах prompt и padding значение -100, на местах ответа
   его ID. Пустой ответ, недостаточная длина и пустой prompt — `ValueError`.
   ID — неотрицательные целые; `True`/`False` запрещены, хотя в Python это
   тоже целые числа.
2. Реализуй `lora_parameters(in_features,out_features,rank)` — число
   параметров A и B. Все размеры — положительные целые, иначе `ValueError`.
3. Вручную проверь сдвиг logits/labels для causal LM: модель предсказывает
   токен i+1 по позиции i. Объясни, почему маскировать padding недостаточно.

CPU, без весов; 1–2 часа. Настоящее дообучение выполняется позже в
MODEL-примере.

`raise ValueError('описание')` — так функция сообщает «мне дали неверные
данные» и останавливается; `check.py` проверяет, что ошибка действительно
возникает. Если исключения ещё не знакомы — см. минимум Python в
[0_lab_setup](../../0_lab_setup/README.md).
