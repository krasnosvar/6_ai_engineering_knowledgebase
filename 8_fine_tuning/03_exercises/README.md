# Маска loss для SFT и число параметров LoRA

Два программных задания и одно письменное. Профиль CPU, без модели и
скачиваний, 1–2 часа. Настоящее дообучение с этими же идеями выполняет
MODEL-пример `02_train_adapter.py` из [примеров](../02_examples/README.md).

## Где писать и как проверять

Решения пиши в [`task.py`](task.py): там уже есть функции
`answer_labels` и `lora_parameters`, внутри которых стоит
`raise NotImplementedError`. Замени эту строку своим кодом. Проверка из
корня репозитория:

```bash
uv run python 8_fine_tuning/03_exercises/check.py
```

Пока функция не написана, проверка останавливается на
`NotImplementedError: TODO: ...` — это ожидаемо и означает «здесь ещё
нет решения». Если твой код возвращает не то значение, увидишь
`AssertionError` с номером строки в `check.py`: открой её и сравни
ожидание со своим результатом. Когда всё верно, печатается
`PASS: 8_fine_tuning student`.

Часть проверок требует, чтобы на неверных входах функция поднимала
`ValueError('описание')`: так функция сообщает «мне дали неверные данные» и
останавливается, вместо того чтобы молча вернуть бессмысленный результат. Если
исключения ещё не знакомы — урок
[исключения](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/1_python_fundamentals/07_exceptions/01_theory/01_exceptions.md)
в Python-базе.

## 1. Метки только на ответе: `answer_labels`

К уроку [как подготовить обучающие
диалоги](../01_theory/02_data_preparation.md).

Дано: `prompt_ids` — список ID токенов инструкции, `answer_ids` — список
ID токенов ответа, `pad_to` — длина, до которой дополняется
последовательность.

Сделать: функция `answer_labels(prompt_ids, answer_ids, pad_to)`
возвращает список меток длины `pad_to`: на местах prompt и padding —
`-100`, на местах ответа — его ID. Пример из урока:
`answer_labels([1, 2], [3, 4], 6) == [-100, -100, 3, 4, -100, -100]`.

`ValueError` ожидается, если:

- prompt или ответ пустой (без ответа нечему учить);
- `pad_to` не целое или меньше суммы длин prompt и ответа;
- среди ID есть не целое число или отрицательное. `True`/`False` тоже
  запрещены, хотя в Python это целые числа 1 и 0.

## 2. Сколько обучает LoRA: `lora_parameters`

К уроку [LoRA](../01_theory/03_lora.md).

Дано: `in_features` (`d_in`), `out_features` (`d_out`) и `rank` (r)
одного слоя.

Сделать: `lora_parameters(in_features, out_features, rank)` возвращает
число обучаемых чисел в A и B. Проверка на числах урока:
`lora_parameters(128, 64, 4) == 768`. Все три размера — положительные
целые, иначе `ValueError` (например, `rank = 0`).

## 3. Письменно: сдвиг logits и labels

К уроку [зачем дообучать модель](../01_theory/01_sft_basics.md).

Для prompt `[5, 6, 7]`, ответа `[8, 9]` и длины 7 выпиши `input_ids`,
`attention_mask` и labels из задания 1. Затем для каждой позиции выхода 0–6
напиши: какие токены модель уже видела, с какой меткой сравнивается выход
(библиотека сравнивает выход позиции i с меткой позиции i+1) и входит ли
позиция в loss. Объясни, почему одной маски padding недостаточно и что
изменится, если вручную сдвинуть labels ещё раз.
