# Память, хвост задержек и trace

Четыре функции и два письменных вопроса. Код пиши в
[task.py](task.py): там уже есть заготовки всех функций, каждая пока
поднимает `NotImplementedError`. Профиль **CPU**, веса не нужны;
ориентир — 2–3 часа.

## Как проверять

Из корня репозитория:

```bash
uv run python 10_serving_and_operations/03_exercises/check.py
```

`check.py` вызывает функции по порядку: `kv_bytes`, `nearest_rank`,
`span_tree_summary`, `redact`. Пока функция не написана, проверка
останавливается на её `NotImplementedError` — это ожидаемо и значит
«дальше пока не проверялось», а не «код сломан». Ошибка `AssertionError`
означает, что функция вернула не то значение; `AssertionError: Expected
ValueError` — что на неверный вход функция не подняла `ValueError`, а
вернула результат. Когда все четыре функции готовы, печатается
`PASS: 10_serving_and_operations student`.

## 1. Память KV cache — `kv_bytes`

Урок: [Как модель становится сервисом](../01_theory/01_serving_basics.md).

Дано: шесть чисел `layers, batch, tokens, kv_heads, head_dim,
bytes_per_value`. Сделать: вернуть число байтов KV cache по формуле из
урока (двойка — key и value). Это оценка только кэша, без весов.

`ValueError`: любой аргумент — не целое число (`int`) или меньше 1.
Ноль токенов или дробная голова — ошибка во входе, а не «пустой кэш».

Проверь себя на игрушечном примере урока: `kv_bytes(2, 1, 10, 2, 4, 2)`
должно вернуть 640, а с 20 токенами — 1280.

## 2. Квантиль по nearest rank — `nearest_rank`

Урок: [Как проверить сервис перед
выпуском](../01_theory/03_release_and_drift.md).

Дано: список задержек `values` и доля `p`, `0 < p ≤ 1`. Сделать:
отсортировать копию списка и вернуть элемент с номером `ceil(p·n)`,
считая с 1 (в Python индекс на единицу меньше). Входной список не
менять: `check.py` проверяет, что первый элемент остался на месте.

`ValueError`: пустой список; `p` вне `(0, 1]`; в списке NaN,
бесконечность или отрицательное число.

## 3. Среднее против p95 (письменно)

Для задержек `[1, 1, 1, 1, 20]` секунд посчитай среднее и p95 (своей
функцией из задания 2). Объясни, что каждое число говорит пользователю и
почему пяти измерений мало для оценки хвоста.

## 4. Собственное время span — `span_tree_summary`

Урок: [Как увидеть, что происходит внутри
запроса](../01_theory/04_llm_observability.md).

Дано: `spans` — список кортежей `(id, parent, start, end)`. `parent` — id
родителя или `None` у корня; время — целые миллисекунды. Сделать: вернуть
словарь `{id: (total, self)}`, где `total = end − start`, а `self` —
`total` минус сумма `total` прямых детей, то есть время, которое не
объясняют дочерние spans. Для пустого списка вернуть `{}`.

Пример: родитель `(request, None, 0, 3000)`, дети длительностью 600 и
600 мс. Тогда у `request` будет `(3000, 1800)` — это вопрос 1 урока.

`ValueError`: элемент — не кортеж из 4 полей; повтор id; нецелое время;
`start < 0` или `end < start`; неизвестный родитель или span сам себе
родитель; ребёнок выходит за интервал родителя; отрицательный `self`
(в этом задании дети одного родителя не пересекаются, значит
отрицательное собственное время — признак ошибки во входе).

Подсказка: ребёнок может стоять в списке раньше родителя, поэтому удобно
сначала собрать все spans по id, а потом считать суммы детей.

## 5. Маскирование — `redact`

Урок: [Как увидеть, что происходит внутри
запроса](../01_theory/04_llm_observability.md), раздел о секретах.

Дано: строка `text`. Сделать: заменить ключи вида `sk-...` на `sk-***`, а
адреса почты — на `<email>`. Ключ: перед `sk` граница слова, после `sk-`
хотя бы один символ из букв, цифр, `_` или `-`. Поэтому `task-42` и
одиночное `sk-` ключами не считаются.

`ValueError`: `text` не строка (например, `None` или `bytes`).

Регулярные выражения (`re.compile`, `sub`, `\b`) — общая тема Python: [урок о
модуле
re](https://github.com/krasnosvar/4_python_my_knowledgebase/blob/main/1_python/6_standard_library/01_theory/04_re_regular_expressions.md).

Письменно: приведи пример персональных данных, которые твоё выражение
пропустит, и что тогда защищает trace.
