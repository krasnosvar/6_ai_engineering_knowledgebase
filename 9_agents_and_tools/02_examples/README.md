# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют весов.
MODEL и embedding читают только локальные файлы: [где взять модели](../../data/models.md).
Пока веса не подготовлены, эти команды завершаются с пояснением; это не успешный запуск.
Для каждого опыта сначала предскажи результат, затем измени одно условие.

## 01_executor.py

Профиль: **CPU**. Разрешённое действие выполнено, запрещённое отвергнуто, цикл ограничен.

```bash
uv run python 9_agents_and_tools/02_examples/01_executor.py
```

Добавь отмену и тест таймаута.

## 02_model_tool.py

Профиль: **MODEL**. Ответ LLM и честный результат проверки/исполнения одного шага.

```bash
uv run python 9_agents_and_tools/02_examples/02_model_tool.py
```

Сравни несколько формулировок; не скрывай invalid_json.

## 03_idempotency.py

Профиль: **CPU**. Повтор ID операции не дублирует симулированное действие.

```bash
uv run python 9_agents_and_tools/02_examples/03_idempotency.py
```

Добавь сохранение журнала и тест двух конкурентных вызовов; исходный пример однопоточный.
