# Разбор: Безопасный исполнитель

Модель только предлагает действие. Исполнитель проверяет его вне модели и не
расширяет права по тексту запроса. После неопределённого результата внешней операции
нужна проверка её статуса по ID; слепой повтор без идемпотентности может дублировать эффект.

[Код решения](solution.py). Из корня:

```bash
uv run python 9_agents_and_tools/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях.
Для освоения темы также нужен твой отчёт и самостоятельный эксперимент из задания.
