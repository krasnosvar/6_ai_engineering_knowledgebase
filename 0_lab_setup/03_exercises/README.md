# Входная диагностика

CPU; 45–90 минут, без модели и скачиваний. Диагностика проверяет весь
[минимум Python для курса](../python_minimum.md): если какой-то пункт не
получается, открой соответствующий раздел этой страницы и вернись.

1. Создай список трёх обращений: словари с ключами `text` и `label`.
2. Напиши функцию подсчёта числа обращений по меткам. Не меняй исходный
   список.
3. Сохрани данные в JSON-файл через `with open(...)`, прочитай их обратно и
   проверь совпадение.
4. Напиши функцию `validate(row)`: если `text` пустой или ключа `label` нет,
   она поднимает `ValueError` с понятным сообщением. Вызови её на неверной
   строке внутри `try/except` и напечатай сообщение ошибки.
5. Напиши класс `Ticket` с `__init__(self, text, label)` и методом
   `short(self, n)`, который возвращает первые `n` символов текста. Преврати
   список словарей из пункта 1 в список объектов `Ticket`.
6. Объясни разницу между параметром модели и параметром командной строки.
7. Модель «запомнила» правильные ответы на все знакомые ей примеры. Почему
   это ещё не значит, что она будет отвечать правильно на новых? Ответь
   своими словами, без терминов; подробно и с метриками это разбирается в
   [разделе 2](../../2_classical_ml/README.md).

Готовность: пункты 1–5 решены без копирования, 6–7 объяснены своими словами.
