# Проверка среды

Профиль CPU, без сети после установки зависимостей. Из корня:

```bash
uv run python 0_lab_setup/02_examples/01_doctor.py
```

Ожидаются Python 3.12 и установленные зависимости. `XPU available: False`
допустим для CPU-профиля. Проверь свободную память и место перед скачиванием
модели.
