# Проверка среды

## 01_doctor.py

Выполняется после урока [на чём будем выполнять
эксперименты](../01_theory/01_hardware.md) и команды `uv sync --frozen`
из него. Профиль **CPU**, сеть и веса моделей не нужны. Скрипт только
читает сведения о машине и ничего не устанавливает.

```bash
uv run python 0_lab_setup/02_examples/01_doctor.py
```

Перед запуском предскажи: сколько RAM и свободного места ты ожидаешь
увидеть и найдёт ли PyTorch видеокарту.

Как читать вывод (пример с машины, на которой готовился курс):

| Строка | Пример | Что означает |
|---|---|---|
| `Python` | `3.12.15` | для курса нужна версия 3.12 |
| `Logical CPUs` | `22` | сколько потоков вычислений видит программа |
| `MemTotal` / `MemAvailable` | `65284964 kB` / `26403772 kB` | вся RAM и сколько можно занять сейчас; 1 ГБ ≈ 1 000 000 kB |
| `Disk available GiB` | `107.7` | свободное место на диске с репозиторием |
| `GPU nodes` | `['/dev/dri/card1', ...]` | файлы-устройства видеокарты; `not visible` — их не видно в этой среде |
| `numpy: installed` и т.д. | `installed` | библиотеки окружения на месте; `not installed` — `uv sync` не выполнен |
| `XPU available` / `CUDA available` | `False` | видит ли PyTorch ускоритель Intel или NVIDIA |

Запуск показывает версию Python, обнаруженные библиотеки и доступные
сведения о машине. Сверь вывод с требованиями: сам по себе успешный запуск
не означает, что все библиотеки установлены. `XPU available: False` для
CPU-маршрута нормален: основной `uv.lock` ставит PyTorch без поддержки
ускорителей. Скрипт не измеряет скорость и не проверяет, поместится ли
конкретная модель: это видно только при её запуске.

Модели курса небольшие: набор файлов языковой модели занимает около
260 MiB, модели для поиска — около 87 MiB. При работе RAM нужно больше,
чем размер файлов; сколько именно, покажет запуск. Подробности — на
[странице моделей](../../data/models.md).

Если напротив библиотеки стоит `not installed in this Python`, проверь,
что запускаешь скрипт через `uv run` из корня репозитория и что
`uv sync --frozen` завершился успешно. При необходимости прочитай
сообщение об ошибке установки и повтори команду после исправления.
