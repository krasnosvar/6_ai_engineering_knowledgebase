# Как проходить курс без скачивания моделей

Начнём с собственных маленьких моделей и встроенных данных. На них можно
увидеть, как считается ошибка, меняются веса и проверяется качество. Готовые
веса нужны позже, чтобы применить эти навыки к настоящей языковой модели. Вся
теория доступна до этого шага; ссылки для ручного получения весов собраны на
[странице моделей](../data/models.md).

Нужен [минимум Python для курса](python_minimum.md): функции, списки,
словари, циклы, файлы, исключения и простые классы. Знания AI и высшей
математики не предполагаются: математические понятия вводятся на маленьких
примерах. Если пока трудно читать Python, начни с [входной
диагностики](03_exercises/README.md) и вернись к первому занятию после
устранения пробелов.

## Первое занятие: от правила к обучению

1. Прочитай [что делает AI-инженер](01_theory/01_rules_and_learning.md). Найди
   различие между правилом, написанным человеком, и параметрами, найденными по
   данным.
2. Пройди [настройку среды](01_theory/02_hardware.md). Установки библиотек
   достаточно: файлы моделей этому занятию не нужны.
3. Разбери [числа, векторы и линейную
   модель](../1_math_and_data/01_theory/01_vectors_and_linear_model.md).
   Посчитай одно предсказание вручную.
4. Прочитай [урок о градиенте](../1_math_and_data/01_theory/02_gradients.md).
   Проследи, как ошибка 17 уменьшается после изменения двух параметров. Ответь
   на вопрос до раскрытия разбора.
5. Из корня репозитория запусти `uv run python
   1_math_and_data/02_examples/01_gradient.py`. В скрипте больше точек, чем в
   ручном примере, но правило изменения весов то же.
6. Измени скорость обучения и объясни наблюдение: ошибка уменьшается быстрее,
   медленнее или начинает расти? Сохрани свой вывод вместе с выбранным
   значением.

Результат занятия — ты можешь объяснить один шаг обучения. Пока не требуется
помнить все названия библиотек или выводить производные без подсказки.

## Как устроено следующее занятие

Открывай README нужного раздела: там указан порядок **всех** его уроков, включая
те, которые вынесены в отдельные файлы. Порядок файлов по алфавиту для чтения не
подходит. Прочитай объяснение, воспроизведи небольшой пример и ответь на
самопроверку. После этого переходи к указанной лабораторной и самостоятельному
заданию.

Если результат отличается от ожидаемого, сначала запиши отличие. Проверь входные
данные, размеры и смысл промежуточных значений. По этой записи проще найти
пробел в понимании, чем по повторному запуску без изменений.

Начать небольшой проект можно до конца курса: классификатор — после раздела 2,
поиск документов — после раздела 7. Возвращайся к нему по мере освоения новых
тем. Для каждого самостоятельного эксперимента сохраняй
[отчёт](../other/experiment_template.md). Не нужно писать отчёт на каждую
прочитанную страницу.

## Когда понадобятся готовые модели

После подготовки весов по ссылкам выполни второй практический проход: генерация
ответа → поиск по смыслу → RAG → SFT/LoRA → выбор инструмента → измерение
генерации. Команды находятся в разделах 5, 6, 8, 9 и 10; у таких примеров указан
профиль MODEL или embedding. Эти шесть запусков пока не проверены выполнением в
текущем окружении.

Без них можно освоить устройство методов и выполнить CPU-часть практики. Для
опыта работы с готовой LLM нужно дополнительно пройти модельные лабораторные,
разобрать реальные ответы и завершить соответствующие части проектов.

## Как выбрать направление

Для основного пути оставь фокус на прикладных LLM, но пройди базовые ML и
нейросети: они объясняют оценку, переобучение и адаптацию. Раздел CV даёт первый
опыт другой задачи на тех же принципах. После него сравни, что тебе интереснее:
документы и диалоги, предсказания по данным или изображения. Полная
специализация в CV потребует дополнительной практики; вводный раздел позволяет
сделать этот выбор осознанно.

Цель маршрута — самостоятельное решение инженерной задачи. Проверяй продвижение
по [критериям проекта](../12_capstones/01_theory/02_competencies.md), а не
только по количеству уроков. Опыт реальной эксплуатации дополняет учебную
подготовку.
