# С чего начинается работа AI-инженера

Начнём с простой задачи: направить обращение пользователя нужной команде. На ней
разберёмся, что означает «модель учится», чем обучение отличается от применения
и какую часть работы выполняет инженер. Знания искусственного интеллекта для
этого раздела не нужны.

## Порядок чтения

1. [Что мы строим и чему будем учиться](01_theory/01_rules_and_learning.md) —
   правила, данные, параметры и карта направлений AI.
2. [Как устроить лабораторию на своём компьютере](01_theory/02_hardware.md) —
   память, процессор, ускоритель и установка окружения.

Читай уроки последовательно. Перед раскрытием разбора ответь на вопросы
самопроверки своими словами; если объяснение пока не получается, вернись к
разобранному примеру.

## Как перейти к практике

После теории пройди входную диагностику Python. Она проверяет функции,
списки, словари, файлы, исключения и классы: всё это встречается в коде
курса. Весь нужный набор конструкций с короткими примерами собран на
странице [минимум Python для курса](python_minimum.md) — открой её, если
какой-то пункт диагностики не получается. Затем выполни команды проверки
окружения из инструкции к примерам. Здесь ещё нет обучения модели.

Все команды выполняются из корня репозитория. [Инструкция к
примерам](02_examples/README.md) содержит команды и ожидаемые результаты. Затем
открой [самостоятельные задания](03_exercises/README.md); [ответы и
разбор](04_exercises_answers/README.md) используй после своей попытки.
