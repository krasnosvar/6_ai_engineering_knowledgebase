# Подготовка среды

В этом разделе подготовим компьютер к запуску примеров: установим
окружение Python, проверим доступные ресурсы и повторим нужные
конструкции языка. Теория AI и математика начинаются в разделе 1.

Предпосылки: базовый Python и умение запускать программу в терминале.
Если не уверен в знаниях, начни с диагностики: она укажет, какие темы
повторить.

## Порядок

1. Прочитай [урок о компьютере и окружении](01_theory/01_hardware.md).
2. Запусти [проверку среды](02_examples/README.md) и изучи её вывод.
3. Пройди [диагностику Python](03_exercises/README.md); после попытки
   сверься с [разбором](04_exercises_answers/README.md). Нужные темы
   собраны на странице [какой Python нужен](python_minimum.md).

## Когда двигаться дальше

Проверка среды запускается, а пункты диагностики Python решены без
подсказок. Затем открывай [раздел 1](../1_math_and_data/README.md):
там начинается теория и объясняется, зачем инженеру математика.
