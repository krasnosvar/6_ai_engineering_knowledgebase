# Разбор: Метрики редкого класса

Классификатор большинства получает accuracy 99%, но recall аварий 0. Выбор
метрики зависит от задачи. Разбиение по строкам не защищает от совпадения
пользователей или исходных документов: проверка ID — необходимый, но не
достаточный контроль, поскольку почти дубликаты могут иметь разные ID.

[Код решения](solution.py). Из корня:

```bash
uv run python 2_classical_ml/03_exercises/check.py --answers
```

Эти проверки подтверждают контракт функций на граничных и обычных случаях. Для
освоения темы также нужен твой отчёт и самостоятельный эксперимент из задания.
