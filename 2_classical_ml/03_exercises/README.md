# Метрики редкого класса

1. Реализуй `binary_metrics(truth,pred)` для непустых одинаковых по длине списков
из 0/1. Верни словарь precision, recall, f1. При нулевом знаменателе значение 0.0.
2. Реализуй `group_overlap(train_groups,test_groups)` — множество пересекающихся ID.
3. На 99 отрицательных и одном положительном примере сравни accuracy и recall
классификатора «всё отрицательное». Объясни цену ошибок для аварийных обращений.
CPU, stdlib; 1–2 часа. Дополнительно сравни слово- и символьный TF-IDF на dev,
который выделишь из train, сохранив встроенный test для одной финальной проверки.
