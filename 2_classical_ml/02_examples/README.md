# Примеры и эксперименты

Команды из корня репы после установки зависимостей. CPU-примеры не требуют
весов. MODEL и embedding читают только локальные файлы: [где взять
модели](../../data/models.md). Пока веса не подготовлены, эти команды
завершаются с пояснением; это не успешный запуск. Для каждого опыта сначала
предскажи результат, затем измени одно условие.

## 01_tickets.py

Профиль: **CPU**. Отчёт precision/recall/F1 и предсказание каждого
test-обращения.

```bash
uv run python 2_classical_ml/02_examples/01_tickets.py
```

Создай dev из train; сравни word и char TF-IDF.

## 02_leakage.py

Профиль: **CPU**. Случайное разбиение строк: 98% test-строк от знакомых
клиентов, accuracy=1.000. Разбиение по клиентам: accuracy=0.560 — запоминание ID
не помогает.

```bash
uv run python 2_classical_ml/02_examples/02_leakage.py
```

Объясни, какие реальные поля могут играть роль ID.

## 03_trees.py

Профиль: **CPU**. Train/validation accuracy для линейной модели, двух деревьев и
boosting. Глубокое дерево: 1.000/0.800 — переобучение; boosting лучший на
validation (0.900).

```bash
uv run python 2_classical_ml/02_examples/03_trees.py
```

Выбери глубину по validation, затем один раз проверь на новом наборе с другим
seed.
