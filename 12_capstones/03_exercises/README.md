# Три итоговых проекта

Проходи по одному. CPU-baseline обязателен. Модельные эксперименты выполняются
позже, после ручной подготовки весов по [ссылкам](../../data/models.md); до
этого нельзя считать модельную часть проекта выполненной.

1. [Ассистент по документации](01_document_assistant.md) — после раздела 7.
2. [Маршрутизация обращений](02_ticket_routing.md) — CPU-baseline
   (эксперимент 1) после раздела 2, модельные эксперименты после раздела 8.
3. [Диагностический агент](03_diagnostic_agent.md) — после разделов 9–10.

Сохраняй проекты в `artifacts/projects/<name>/` для личной работы. Если
публикуешь портфолио, перенеси проверенные исходники в отдельный
Git-репозиторий, исключив секреты, скачанные веса и данные с несовместимой
лицензией. Эти проекты автоматически не создаются из решений: самостоятельная
реализация — часть проверки компетенций.

На каждый проект ориентируйся на 20–40 часов для первой версии и дополнительное
время на ошибки, изменения требований и защиту. Это оценка, не лимит обучения.
