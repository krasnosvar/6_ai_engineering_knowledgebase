# Разбор архитектур и ориентиры ревью

Готового проекта для копирования нет: эти задания проверяют самостоятельное
решение. Используй ориентиры после первой реализации.

## Ассистент

Раздели ingestion, retrieval, сбор контекста и генерацию. Источник хранится
независимо от фрагмента. ACL входят в запрос поиска; индекс содержит версию.
Сначала локализуй, потерян ли документ при подготовке, ранжировании или сборке
контекста. Наличие цитаты не заменяет ручную проверку поддержки утверждения.
Отказ оценивается отдельно.

## Маршрутизация

Простой ML может выигрывать по цене и задержке. Для LLM проверь, не связано ли
улучшение только с форматом ответов или пересечением шаблонов. Адаптер должен
сохраняться и загружаться с правильной базовой моделью. Решение по порогу отказа
выбирается на dev. Отдельно проверь новый класс и редкие ошибки. Учебный
HTTP-сервис не заменяет deployment и сохранение артефактов.

## Агент

Наблюдаемое состояние песочницы важнее финальной фразы. Права определяются
исполнителем. Лимит шагов нужен даже для полностью корректного JSON. Долгая
история не заменяет структурированное состояние. Retry безопасен только при
определённых гарантиях операции.

Для всех проектов: оцени по [рубрике](../01_theory/02_competencies.md), приложи
отчёт и проведи изменение требований без просмотра готового примера. При
отсутствии реального MODEL-запуска так и отметь; тест исполнителя не доказывает
качество агента.
